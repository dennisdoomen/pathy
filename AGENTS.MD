# Packaged C# sources

The `Pathy` and `Pathy.Globbing` NuGet packages include every `*.cs` file in their project directory as consumer-compiled source.

When adding or changing one of these files:

- Start it with `// <autogenerated />` and add `#pragma warning disable` near the top of the file, before its namespace code.
- Use UTF-8 without a byte-order mark and a block-scoped `namespace Pathy`.
- Add `#nullable disable` after the warning pragma to every packaged source file.
- Types compiled into the consumer must be `internal` and include `Embedded` and `DebuggerNonUserCode`. Expose them as `public` only inside `#if PATHY_PUBLIC`.
- Keep optional dependencies behind their existing compilation symbols, so consumers do not need dependencies they did not opt into.
- Pack the affected project and inspect its `contentFiles/cs` entries to verify every shipped C# file follows these rules.
